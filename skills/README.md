# Install the `opinionated-ts-result` Skill from `@opinionated-ts/result`

This skill teaches your AI coding agents how to use [`@opinionated-ts/result`](https://github.com/opinionated-ts/result) consistently and take advantage of its type-safe error factories.

Install the `opinionated-ts-result` skill with [Vercel's Skills CLI](https://github.com/vercel-labs/skills).

Install the skill by choosing the command for your preferred package manager:

<!-- cspell:ignore bunx -->

```bash
npx skills add opinionated-ts/result

# bunx skills add opinionated-ts/result
# pnpm dlx skills add opinionated-ts/result
# yarn dlx skills add opinionated-ts/result
```

The CLI finds the skills in this repository and prompts you to choose which agent to install them for and whether to install them globally or in the current project.
