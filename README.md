# @opinionated-ts/result

Type-safe functional error handling with `ok` and `error` results for the [**Opinionated TS ecosystem**](https://github.com/opinionated-ts).

> [!WARNING]
> This project is in a very early stage and is **not ready for use**.
>
> It should be considered stable only once it reaches **`1.0.0` or later**.
